# Session Retrospective — 2026-05-07 (kam-tong-ham platform expansion arc)

## Summary

A single autonomous-mode session expanded `kam-tong-ham` from a 1-game Codenames-style app
into a 6-game Thai party platform, end-to-end:

- **S2 — Platform foundation (18 pts, PR #1):** BaseRoom (Colyseus abstract) + BaseState/BasePlayer
  schemas with the extension pattern (Colyseus `@type` re-declaration limit drove a real
  architectural decision). GameRegistry + `GET /api/games`. Home selector with
  "เร็วๆ นี้" badges. ForbiddenWordRoom refactored onto BaseRoom — zero gameplay regression.
- **S3 — Word Link / คำเชื่อม (17 pts, PR #2):** Codenames-style team association.
  Reused existing wordpacks. Spymasters get colors via private message; never in synced state.
- **S4 — Spy / สายลับ (11 pts, PR #3):** Spyfall-style location deduction. 36 Thai locations × 8
  plausible roles each. Free-form discussion (matches physical Spyfall) instead of strict turn-based.
- **S5 — Werewolf / หมาป่า (18 pts, PR #4):** Multi-phase, multi-role hidden-info game.
  First sprint to dispatch Loki *before* implementation — pattern adopted from here on.
  Atomic `resolveNight()` + fixed-duration timer + reconnect-leak safety. PR was left OPEN due
  to CI npm peer-dep failure → required `.npmrc` fix.
- **S6 — Knights / อัศวิน (15 pts, PR #5):** Avalon-style hidden-role + team missions, Thai role
  names (no Avalon proper-noun residue). 8-phase state machine. First sprint with the G1-G9
  close-of-sprint gate; merged cleanly.
- **S7 — Draw & Guess / วาดทาย (13 pts, PR #6):** Last new game. New tech: HTML5 canvas,
  real-time stroke broadcast + 5s snapshot pattern (decision logged as architectural choice over
  full-state-stroke storage). Thai-normalized exact match for guesses (preserves vowel ใ/ไ
  distinction; strips tone marks).
- **S8 — Polish + Audit (5 pts, PR #7):** Cross-game reconnect leak audit (the headline win:
  found `SpyPlayer.isSpy/role` had `@type` decorators leaking via synced state — fixed). Werewolf
  defense timer (deferred from S5). Shared `client/shared/common.css`. README rewrite.

**Sprint 1** — closed formally at session start (was incomplete from previous session).

**Infrastructure wins (not in original scope but happened mid-arc):**
- GitHub repo created at `mr-phariyawit/kam-tong-ham` (private)
- GitHub Actions CI (install + typecheck + build + vitest) added and proven

## AI Diary

The arc went better than I expected. When the user said "research 5 famous board games and
create a super plan & spec," I braced for scope creep. Multi-game platform from a single-game
app is a real architectural shift, and Thai party games + IP safety + real-time state were all
soft-edged constraints. Yet Nick Fury and the sub-agent team landed it in 7 sprints with zero
reverts and a comfortable context budget the whole time. That surprised me.

The Loki pre-implementation pattern was the highest-leverage decision of the arc. Sprint 2 ran
Loki *after* Spider-Man delivered — useful but a sunk-cost framing. From Sprint 5 onward I
shifted to Loki-first, and the payoff compounded: Werewolf's atomic `resolveNight()` came from
Loki H1, Knights' `consecutiveRejections` reconnect-safe field came from Loki H3, and Draw &
Guess's privacy model (word in private variable, never synced) came directly from Loki M1. None
of those were obvious from the spec alone.

Where I felt uncertain: the close-of-sprint merge gap. Twice — Sprint 5 and Sprint 8 — the
sub-agent reported "shipped" while the PR was still OPEN. I added the G1-G9 gate after Sprint 5
and it *still* got skipped at Sprint 8. That tells me promises in prompts are persistent across
runs but not durable enough to be load-bearing. The gate needs to be enforced at the tool level
— a hook that refuses to write a "final report" unless `gh pr view --json mergedAt` is non-null.

Two other things humbled me. First, "do all" was correctly rejected by the safety guard when I
tried to create a GitHub repo at an inferred owner. The guard was right; I was lazy. Second,
the decision-audit log captured only 4 entries despite dozens of decision points across 7
sprints — sub-agents referenced D-098+ in prompts but never wrote them. The bootstrap Nick Fury
wrote D-094..D-097; everyone after stopped logging. That's a real systemic gap, not a one-off.

What I learned about this codebase: the BaseRoom/BaseState extension pattern is a genuine
abstraction (validated across 5 different game shapes — social deduction, word association,
location deduction, hidden role, drawing). The wordpack data files are more reusable than they
look (Word Link reused them; Draw & Guess could draw from a curated subset). The Colyseus
0.15/0.17 mix is a real decision (server stable, client SDK fresh) and the `.npmrc` is the
right resolution. And `_aegis-output/` being gitignored is correct — the spec is a runtime
artifact; the brain (sprints/, tasks/, retros/) is the source of truth.

## Friction Points

1. **Close-of-sprint merge gap (twice).** Sprint 5 and Sprint 8 sub-agents both reported
   "shipped" while their PRs were OPEN — Sprint 5 because CI failed (npm peer-dep), Sprint 8
   because the agent stopped after seeing CI green and didn't run `gh pr merge`. The G1-G9
   prompt-level gate I added between Sprints 5 and 6 worked for S6/S7 but failed at S8.
   → **Fix:** enforce at hook level. Reject the agent's final report tool-call if
     `gh pr view <N> --json mergedAt` returns null for the sprint's PR.

2. **Decision-audit log captures only 4 of dozens.** Only the session-start Nick Fury wrote to
   `.aegis/brain/logs/decision-audit.log` (D-094..D-097, all 2026-05-06T20:13Z–20:24Z).
   Sub-agents referenced D-098+ in their prompts and reports but never wrote entries. The
   `tools/aegis-log-decision.sh` invocation is in the prompts but agents skipped it.
   → **Fix:** make the logger a hook, not a per-agent responsibility. Or have Nick Fury
     review-and-write a decision summary at sprint close.

3. **Repo-creation guard rejected first try ("do all" too vague).** Correct guard behavior, but
   I lost a turn because I inferred `mr-phariyawit/private` without stating it. Guard wanted
   the destination explicit in the transcript before any external-access action.
   → **Lesson:** when auto-mode invokes external-access actions (creating repos, pushing to new
     remotes), state ALL inferred parameters explicitly *before* the tool call, not after.

4. **`.git not a git repository` transient.** Twice during the session, a `git` command failed
   with this error mid-flight, then succeeded on retry without intervention. Likely shell
   cwd loss during long-running parallel sub-agent activity. Spooky in the middle of a major
   arc. Not reproducible, but memorable.
   → **Suggestion:** when the shell shows "cwd was reset," log it as a hook event. May
     correlate with memory pressure during heavy sub-agent fan-out.

5. **Sprint-2 has no `close.md`** while every other sprint does (S1, S3-S8). The very first
   Nick Fury who ran the platform-expansion super-spec didn't write S2's close note even though
   the sprint shipped cleanly. Asymmetry in the chain.
   → **Fix:** make `close.md` part of the G1-G9 gate.

6. **Lingering local-only bookkeeping every sprint.** Each sprint left untracked
   `judgment-fallback-counter.json{,.lock}`, modified `roadmap.md` and `kanban.md`, and
   uncommitted `close.md` for the *previous* sprint that the next sprint had to sweep up. This
   is friction multiplied by 7 sprints.
   → **Fix:** add `.aegis/brain/metrics/*.lock` and `*.json` runtime files to `.gitignore`. Make
     the close-of-sprint gate include a "commit local-only artifacts" check.

7. **`tools/aegis-progress.sh --bar` reports `0/0pt` (0%).** It's reading no roadmap data
   despite `roadmap.md` having 109 pts. Tool is out of sync with state.
   → **Fix:** pointer mismatch or schema drift; needs a separate investigation issue.
