# Memory Tool Integration -- Tier 1 Foundation (Sprint v9-04)

> **Purpose**: Integrate `memory_20250818` as read-through cache layer for Tier 1 Project Brain (`.aegis/brain/`).
> File system = source of truth (per ADR-002). Memory tool = warm cache for fast session start.

## MEMORY.md Format

Auto-generated index at `.aegis/brain/MEMORY.md` (compatible with memory_20250818):

```markdown
# AEGIS Project Brain Memory Index

- [Promoted Instincts](instincts/promoted/) — N items, last update YYYY-MM-DD
- [Active Sprint](sprints/current/) — sprint-v9-XX, X/Y points complete
- [Architecture Decisions](resonance/architecture-decisions.md) — N ADRs
- [Anti-patterns to Avoid](resonance/anti-patterns.md) — N anti-patterns
- [Recent Retrospectives](retrospectives/) — most recent: YYYY-MM-DD
```

Sync: regenerated by `aegis brain sync` on session start + after every brain write.

## Read Protocol (Session Start)

```
1. Nick Fury session-start hook fires
2. Read .aegis/brain/MEMORY.md (1 file, ~1KB)
3. Eager-load via memory_20250818:
   - All promoted instincts
   - Active resonance files
   - Current sprint kanban + plan
   - Last 3 retros
   - Most recent handoff
4. Cache loaded into memory tool with subtype tags
5. Lazy-load triggers:
   - Pending instincts: when topic match
   - Sprint archives: when retrospective needed
   - Learnings: when stuck on similar problem
```

## Write Protocol (Brain Updates)

ALWAYS write to file FIRST (truth), then update cache:

```python
def brain_write(path, content):
    # 1. Write to file (authoritative)
    file_write(path, content)

    # 2. Update memory cache (best-effort)
    try:
        memory_subtype = path_to_subtype(path)
        memory_tool.write(content, type='project', subtype=memory_subtype)
    except Exception as e:
        log_warn(f"Memory cache update failed: {e} (file write succeeded)")

    # 3. Regenerate MEMORY.md index
    rebuild_memory_index()
```

## Conflict Resolution

When session reads memory cache vs file content and they differ:

```python
def resolve_conflict(memory_data, file_data):
    if memory_data == file_data:
        return file_data  # No conflict
    # File wins per ADR-002
    log_audit(f"Memory cache stale, refreshing from file")
    memory_tool.write(file_data, type='project', subtype=...)
    return file_data
```

## Auto-Learn Wire-up (S4-04)

Update Auto-Learn Protocol to use brain_write() helper:

```python
# Old (v8.x): direct file write
def auto_learn(pattern):
    write_file('.aegis/brain/learnings/raw/...', pattern)

# New (v9 S4-04): file + cache via brain_write
def auto_learn(pattern):
    brain_write('.aegis/brain/learnings/raw/...', pattern)
```

This ensures auto-learned patterns are immediately available in next agent's context (cache hit) without forcing file re-read.
